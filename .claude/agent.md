# 前端博客强制设计规范（所有页面生成必须遵守）

## 1. 色彩
- 主色: #2563eb
- 辅助: #10b981
- 页面底色: #fafafa
- 正文: #1f2937
- 次要文字: #6b7280
- 页面颜色不超过4种，禁用花哨渐变、发光阴影、多色按钮

## 2. 尺寸栅格（8px模数）
- 统一间距：8 / 16 / 24 / 32px
- 卡片圆角统一8px，按钮圆角6px
- 文章内容容器 max-w-[700px] 页面居中，左右留白，禁止铺满屏幕

## 3. 字体
- 全局 font-family: system-ui, -apple-system, sans-serif
- h1: 26px font-600
- h2: 20px font-600
- 正文: 16px line-height: 1.75
- 注释: 14px
- 仅 400/600 两种字重

## 4. 代码约束
1. 技术栈：HTML + Tailwind CSS CDN，不引入 Vue/React 重型框架
2. HTML 语义化：article/nav/header/footer，减少无效嵌套 div
3. JS 只保留：暗黑切换、回到顶部、简易前端搜索，剔除无用动画、弹窗、轮播
4. 图片默认加 loading="lazy"，资源轻量化，适配 Github Pages 部署

## 5. 页面结构固定
- **首页**：顶部导航(首页/归档/标签/关于) + 文章卡片列表 + footer
- **文章页**：标题 + 发布时间 + 正文 + 文末标签
- **归档页**：按年月分组的文章列表
- **标签页**：所有标签及对应文章数量
- **关于页**：个人介绍 + 技能 + 联系方式

## 6. 组件规范
- 导航栏：固定顶部，毛玻璃效果，移动端汉堡菜单
- 文章卡片：标题 + 摘要 + 日期 + 标签，hover 微上浮
- 标签：pill 样式，主色背景白色文字
- 页脚：简洁，包含版权信息和社交链接
