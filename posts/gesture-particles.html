Three.js + MediaPipe Hands

手势控制粒子系统 - 玩转 3D 交互

2026-06-04 · 5 分钟阅读 · Three.js 交互
🎮 在线体验
需要摄像头权限，支持手势控制
立即试玩 →

这是一个基于 Three.js 和 MediaPipe Hands 的 3D 粒子交互系统。通过摄像头检测手势，可以实时控制粒子的形态和运动。

✨ 功能特性

🌌
8 种粒子形态
银河、爱心、DNA、环结、蝴蝶、花朵、神龙、土星
🌈
6 种配色方案
幻彩霓虹、赛博朋克、深海幽蓝、烈焰熔岩、樱花飘落、极光幻境
✋
手势控制
张开扩散、握拳收拢、移动旋转
✨
视觉特效
Bloom 泛光、星空背景、粒子发光

🖐️ 手势说明

手势 效果 说明
✋ 张开手掌 扩散放大 五指张开，粒子向外扩散
👊 握拳 收拢缩小 握紧拳头，粒子向中心聚拢
🤚 移动手掌 旋转视角 左右上下移动，旋转 3D 视角

🛠️ 技术栈

  • Three.js - 3D 图形渲染引擎
  • MediaPipe Hands - Google 的手部追踪模型
  • WebGL - 硬件加速图形渲染
  • GLSL Shader - 自定义粒子着色器

📂 项目结构

particles.html          # 主页面（单文件，可直接运行）
├── Three.js            # 3D 渲染
├── MediaPipe           # 手势识别
├── Particle System     # 粒子系统
└── UI Controls         # 控制面板

🚀 如何使用

有两种方式体验：

方式一：在线体验（推荐）

直接访问 在线演示页面，允许摄像头权限即可。

方式二：本地运行

# 下载文件后，用本地服务器运行
python -m http.server 8080

# 然后访问 http://localhost:8080/particles.html

💡 设计思路

这个项目的核心是实时手势识别与粒子系统的结合：

  • 使用 MediaPipe 检测手部 21 个关键点
  • 通过指尖到手掌中心的距离判断手势
  • 将手势数据映射到粒子系统的缩放和扩散参数
  • 使用 Three.js 的 BufferGeometry 高效渲染上万个粒子

📝 后续计划

  • 添加更多粒子形态（音乐可视化等）
  • 支持双手手势控制
  • 添加粒子连线效果
  • 优化移动端体验
