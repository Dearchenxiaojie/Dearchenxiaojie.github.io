GitHub Pages 免费搭建个人网站指南

2026-06-03 · 8 分钟阅读

GitHub Pages 是 GitHub 提供的免费静态网站托管服务，非常适合搭建个人博客、项目文档等。

什么是 GitHub Pages？

GitHub Pages 可以直接从 GitHub 仓库托管静态网站。它支持 HTML、CSS 和 JavaScript 文件，无需服务器配置，完全免费。

快速开始

搭建 GitHub Pages 只需要几个简单的步骤：

  1. 创建一个名为 username.github.io 的仓库
  2. 上传你的 HTML 文件
  3. 在仓库设置中启用 GitHub Pages
  4. 等待几分钟，你的网站就上线了！

使用自定义域名

如果你想使用自己的域名，可以在仓库根目录创建一个 CNAME 文件，里面写上你的域名。然后在域名服务商处添加 CNAME 记录指向 username.github.io。

# CNAME 文件内容
www.yourdomain.com

自动部署

GitHub Pages 支持从特定分支自动部署。你可以使用 GitHub Actions 来自动构建和部署你的网站。
