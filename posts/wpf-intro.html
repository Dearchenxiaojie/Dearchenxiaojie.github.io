WPF 入门：从零开始构建桌面应用

2026-05-28 · 12 分钟阅读

WPF（Windows Presentation Foundation）是微软推出的桌面应用程序开发框架，基于 .NET 平台，提供了强大的 UI 设计能力。

WPF 是什么？

WPF 是一个用于构建 Windows 桌面应用程序的 UI 框架。它使用 XAML（一种基于 XML 的标记语言）来定义界面，支持数据绑定、动画、样式等高级特性。

WPF 的核心概念

  • XAML - 用于声明式定义 UI 的标记语言
  • 数据绑定 - 将 UI 元素与数据源连接
  • 样式和模板 - 自定义控件外观
  • 路由事件 - 事件在元素树中传播

创建第一个 WPF 应用

在 Visual Studio 中创建 WPF 项目非常简单：

<Window x:Class="MyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Hello WPF" Height="350" Width="525">
    <Grid>
        <Button Content="点击我"
                HorizontalAlignment="Center"
                VerticalAlignment="Center"
                Click="Button_Click"/>
    </Grid>
</Window>

常用控件

WPF 提供了丰富的内置控件：

  • Button - 按钮
  • TextBox - 文本框
  • ListView - 列表视图
  • DataGrid - 数据网格
  • TabControl - 选项卡控件

WPF 是一个功能强大的框架，适合开发现代化的桌面应用程序。继续深入学习，你会发现它的更多魅力！
