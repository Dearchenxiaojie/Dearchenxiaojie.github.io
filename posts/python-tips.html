Python 实用技巧分享

2026-06-01 · 10 分钟阅读

Python 是一门非常优雅的编程语言，有很多实用的技巧可以提高开发效率。本文整理了一些我常用的技巧。

列表推导式

列表推导式是 Python 中非常强大的特性，可以用一行代码创建复杂的列表：

# 传统方式
squares = []
for x in range(10):
    squares.append(x ** 2)

# 列表推导式
squares = [x ** 2 for x in range(10)]

# 带条件筛选
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]

装饰器

装饰器是 Python 中非常优雅的设计模式，可以在不修改原函数代码的情况下扩展功能：

def timer(func):
    import time
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 运行时间: {end - start:.2f}秒")
        return result
    return wrapper

@timer
def slow_function():
    import time
    time.sleep(1)

上下文管理器

使用 with 语句可以自动管理资源，确保资源被正确释放：

# 文件操作
with open('file.txt', 'r') as f:
    content = f.read()
# 文件会自动关闭

# 自定义上下文管理器
from contextlib import contextmanager

@contextmanager
def managed_resource():
    resource = acquire_resource()
    try:
        yield resource
    finally:
        release_resource(resource)

f-string 格式化

Python 3.6+ 引入的 f-string 是最方便的字符串格式化方式：

name = "World"
print(f"Hello, {name}!")

# 支持表达式
print(f"2 + 3 = {2 + 3}")

# 格式化数字
pi = 3.14159
print(f"π ≈ {pi:.2f}")

掌握这些技巧可以让你的 Python 代码更加简洁优雅。继续学习，探索更多 Python 的奥秘吧！
