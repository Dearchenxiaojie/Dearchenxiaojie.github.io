Hello World - 我的第一篇博客

2026-06-04 · 5 分钟阅读

终于搭建好了自己的个人博客！🎉

为什么我要搭建这个博客？

作为一个计算机专业的学生，我一直想要一个属于自己的空间来记录学习过程和技术心得。之前尝试过很多平台，但总觉得不够自由，于是决定自己动手搭建一个。

技术选型

经过一番调研，我选择了以下技术栈：

  • HTML + Tailwind CSS - 轻量级，无需构建工具
  • GitHub Pages - 免费托管，自动部署
  • Claude Code - AI 辅助开发，提高效率

未来计划

我计划在这个博客上分享：

  • 编程学习笔记和技术教程
  • 项目开发过程中的经验和踩坑记录
  • 一些有趣的技术探索和实验

希望这些内容能够帮助到同样在学习路上的朋友们！
