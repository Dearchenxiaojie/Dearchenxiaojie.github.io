## 🚀 网络加速

### Watt Toolkit（原 Steam++）

> 免费开源的多功能工具箱，支持 GitHub 加速

- **官网**：https://steampp.net
- **下载**：https://steampp.net/download
- **特点**：
  - ✅ 完全免费
  - ✅ 支持 GitHub 加速
  - ✅ 支持 Steam、Epic 等游戏平台
  - ✅ 无需注册
  - ✅ 支持 Windows/Mac/Linux

**使用方法**：
1. 下载并安装
2. 打开软件，找到「网络加速」
3. 勾选「GitHub」
4. 点击「一键加速」

### GitHub520

> 通过修改 hosts 文件加速 GitHub

- **项目地址**：https://github.com/521xueweihan/GitHub520
- **原理**：获取 GitHub 最新 IP，绕过 DNS 污染
